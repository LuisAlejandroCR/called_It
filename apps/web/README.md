# Web camera demo

Start the local server and web app as described in the root README. The review preview is a static placeholder; the separate camera panel requests permission only after the operator clicks Enable camera. Only a small crop is sampled in browser memory, and only metrics, time and hash are sent. Select the documented red-pixel rule for the deterministic demo or use UNKNOWN without camera. The classifier is uncalibrated; measurements from the client can be forged.
